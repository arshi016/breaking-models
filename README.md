Hands-on labs from my **"Breaking Models"** sessions on AI security. One folder per session.

| Session | Topic |
|---|---|
| [`session-01-supply-chain`](session-01-supply-chain/) | AI supply chain: model files, CI pipelines, Ray, MCP servers |

All labs run on localhost with harmless payloads (`echo PWNED`, `whoami`, a fake key).
Read the code before you run it. Each lab is only a few lines.
